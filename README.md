# Teste Prático - Iniflex

Repositório contendo a resolução do desafio técnico de programação Java para a vaga de Desenvolvedor na Progedata.

## 🚀 Sobre o Projeto

Este projeto consiste em um sistema de gerenciamento de funcionários de uma indústria, realizando operações de inserção, remoção, transformação de dados, agrupamentos e cálculos estatísticos baseados em informações contábeis e fiscais.

## 🛠️ Tecnologias Utilizadas

*   **Java 11+**
*   **Java Streams API** para manipulação eficiente de coleções.
*   **java.time (LocalDate)** para manipulação moderna de datas.
*   **java.math (BigDecimal)** para garantir precisão em cálculos financeiros/monetários.

## 📌 Requisitos Implementados

1.  **Modelo de Dados:** Classe `Pessoa` e `Funcionario` com herança.
2.  **Inserção de Dados:** População da lista conforme tabela fornecida.
3.  **Remoção:** Exclusão dinâmica de registros específicos.
4.  **Formatação:** Saída de dados seguindo padrões brasileiros (dd/MM/yyyy e separadores de milhar/decimal).
5.  **Cálculos Fiscais:** Reajuste salarial de 10%.
6.  **Agrupamentos:** Implementação de `Map<String, List<Funcionario>>` para organizar por função.
7.  **Filtros de Data:** Identificação de aniversariantes em meses específicos.
8.  **Lógica de Idade:** Cálculo de anos de vida e identificação do registro mais antigo.
9.  **Ordenação:** Organização alfabética da lista.
10. **Estatísticas:** Somatório total de custos de folha e cálculo de proporção sobre o salário mínimo nacional.
